# Sensor: MPU6050 (GY-521)

The MPU6050 is the only sensor in the project: it provides the motion data that
the fall-detection algorithm runs on.

## Characteristics

| Property | Value |
|---|---|
| Type | 6-axis IMU (MEMS) — tri-axial accelerometer + tri-axial gyroscope |
| Module | GY-521 breakout |
| Interface | I²C |
| I²C address | `0x68` (with AD0 tied to GND) |
| Supply voltage | 3.3V (from the ESP32 3.3V rail) |
| Accelerometer scale used | ±4g → 8,192 LSB/g |
| Gyroscope scale used | ±500°/s → 65.5 LSB/(°/s) |
| Internal filter (DLPF) | ~94 Hz, to preserve the impact peak |
| Output | 16-bit per axis, read in one 14-byte I²C burst |

Datasheet: [`../../../components/datasheets/MPU-6050_product_specification_rev3.4.pdf`](../../../components/datasheets/MPU-6050_product_specification_rev3.4.pdf)

## Pinout (sensor → ESP32)

| MPU6050 pin | ESP32 pin | Function |
|---|---|---|
| VCC | 3.3V | Power |
| GND | GND | Ground |
| SCL | GPIO 22 | I²C clock |
| SDA | GPIO 21 | I²C data |
| XDA / XCL / AD0 / INT | — | Not used |

## Code

The full firmware is in [`../../main/main.ino`](../../main/main.ino). The two
functions that talk directly to the sensor are reproduced below.

Sensor configuration (scale, filter, wake-up):

```cpp
void initMPU() {
  Wire.beginTransmission(MPU_ADDR);
  Wire.write(0x6B); Wire.write(0x00);   // PWR_MGMT_1: wake from sleep
  Wire.endTransmission(true); delay(100);

  Wire.beginTransmission(MPU_ADDR);
  Wire.write(0x1A); Wire.write(0x02);   // CONFIG: DLPF ~94 Hz
  Wire.endTransmission(true);

  Wire.beginTransmission(MPU_ADDR);
  Wire.write(0x1C); Wire.write(0x08);   // ACCEL_CONFIG: ±4g
  Wire.endTransmission(true);

  Wire.beginTransmission(MPU_ADDR);
  Wire.write(0x1B); Wire.write(0x08);   // GYRO_CONFIG: ±500°/s
  Wire.endTransmission(true);
}
```

Reading all 14 bytes (accelerometer + temperature + gyroscope) in one burst:

```cpp
bool readSensor(int16_t &ax, int16_t &ay, int16_t &az,
                int16_t &gx, int16_t &gy, int16_t &gz) {
  Wire.beginTransmission(MPU_ADDR);
  Wire.write(0x3B);                       // ACCEL_XOUT_H
  Wire.endTransmission(false);
  if (Wire.requestFrom(MPU_ADDR, 14, true) < 14) return false;
  ax = Wire.read() << 8 | Wire.read();
  ay = Wire.read() << 8 | Wire.read();
  az = Wire.read() << 8 | Wire.read();
  Wire.read(); Wire.read();               // temperature (discarded, must be read)
  gx = Wire.read() << 8 | Wire.read();
  gy = Wire.read() << 8 | Wire.read();
  gz = Wire.read() << 8 | Wire.read();
  return true;
}
```

## Output (Serial Monitor, 115200 baud)

The firmware prints the live readings to the Serial Monitor. Below is a typical
output showing a confirmed fall (free fall → impact → rest):

```

Accel:13980 Gyro:8600 Jerk:52000 FF:1 ROT:1 IMP:0
```

Reading legend: `Accel` = acceleration magnitude (LSB), `Gyro` = gyroscope
magnitude (LSB), `Jerk` = rate of change of acceleration (LSB/s), `FF`/`ROT`/`IMP`
= the free-fall / rotation / impact flags of the state machine.
